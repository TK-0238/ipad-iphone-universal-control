# MouseLink 0.2.1 — 安全性の回帰検証

## 変更対象
基準コード: 359a7941a57078bfe9025c6a5dbf08ade8983f1e。実行機器・前面アプリ限定・日本語の読み入力という機能範囲は変更しない。署名済みIPAではなくSwift Playground用ソースを配布する。実機のペアリング、文字/マウスの無線転送、日本語IME、iPhoneアプリ内のEnter結果は未検証。

## 再現と修正
- 同一UUIDの高速再接続: 接続の世代を導入。古い文字・Enter・解除を新しい接続へ流さない。転送中の接続構成変更では残りを破棄し、保持キーを残さないため接続を解除する。別受信先の購読変更も安全側に倒して停止する。重複した購読通知は無視し、入力中のキーを不要な初期ゼロ通知で解除しない。
- マウス停止の反復: 解除期限を延ばさず、解除済みの入力を追加しない。無効な開始時刻で既存の解除待ちを消さない。
- 遅い送信可能通知: 実際の書き込み直前にも時刻、前面状態、ポインターロック、接続世代を検査。古い移動を流さない。
- Bluetooth初期通知: 新しい受信先向けのゼロ状態を全端末へbroadcastせず、その受信先だけへ順序を保って送る。
- 送信バッファ混雑: マウス・キーボード・初期通知で共通の再開待ち状態を使う。
- Suspend/Protocol: Control Pointを実際に書き込み可能に修正。別Characteristicの購読でSuspendが解除されないよう、購読・Boot/Reportモード・休止状態を一括管理する。
- 古いコールバック/サービス登録失敗: manager/Characteristicの同一性を確認し、古い遅延タスクをキャンセルする。電源変化後に古い登録済み状態を再利用しない。
- 文字ボタン: 受信先と無関係な後回しの送信を残さず、その場で下書きを検証する。再入時に別の送信を進めない。
- 極端な時計値、遅れて得たポインターロックを拒否する。

## 検証方法
既存テストに追加して、Coreの境界値・状態遷移・長文の押下/解放順序・中止位置を検証する。20,000回の小数マウス移動と10,000回の購読/休止/再接続状態遷移を固定乱数で試験する。さらに2台の入力端点・モード・休止状態の全4,096組と不正Protocol値254通りを検査する。これらは長時間の実機無線試験ではない。

Native testsは実際のTypingSessionからテスト用送信先までを検証し、CoreBluetoothのCharacteristic生成とHID report mapのサイズ整合も調べる。iPad UIは下書き保存、未接続送信禁止、上限超過表示、横向き、大きい文字サイズを検証する。

Pythonの検証は生成物のソース結線・上流SHA・完全なAGPL同梱を調べる静的検査であり、Bluetooth動作の証明ではない。Debug/Releaseの同一Coreテストは同じ項目の再実行として数え、件数を水増ししない。

## 再現可能な実行
```
swift test --package-path MouseLink
swift test --package-path MouseLink -c release
python3 MouseLink/tools/package_keyboard_app.py
python3 MouseLink/tools/test_hardening.py -v
```
Apple SDKが必要なNative/UI/端末向けReleaseビルドはGitHub Actionsが実施し、ログ・実画面・ソースZIPを保存する。端末向けコンパイル成功を実機導入成功とは表記しない。元ソースと固定コミットのAGPLライセンスは保持する。レビューは作成者の自己レビューで、第三者監査ではない。

画面証跡: 横向きでアプリ部分のスクリーンショットに黒帯・欠落を認めたため、最終検証は端末画面全体のスクリーンショットとウインドウ内の操作部品の座標チェックを組み合わせる。見かけのUI成功だけで画像検証済みとはしない。
