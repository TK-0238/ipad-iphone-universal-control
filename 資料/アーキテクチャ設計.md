# アーキテクチャ設計詳細

## 1. ロールとセッション
- **Controller**: 入力をキャプチャし、Displayへ送信。必要に応じてDisplay画面を受信してミラー表示も可能。
- **Display**: ReplayKit/Metalレイヤで画面フレームを生成し、Controllerへ送信。Controllerからの入力を自身のUIに反映。
- **Mirror**: 片方の画面をもう片方にそのまま表示。内部的にはDisplay + ViewOnly Controller の統合。

`SessionCoordinator` は以下の段階で接続を管理する:
1. `MultipeerConnectivity` による発見と招待
2. `NWConnection` (bonjourベース) を TLS で貼り直し、高速データチャネルとする
3. `SessionKey` ネゴシエーション（Curve25519）
4. 論理ストリームの確立: `control`, `input`, `video`, `telemetry`

## 2. 入力中継
- `InputCaptureView` (SwiftUI) が背後の `InputCaptureController` (UIViewControllerRepresentable) を保持。
- `UIKeyCommand` と `UIKeyboardHIDUsage` でハードウェアキーボードを検出。
- `UIPanGestureRecognizer` + `UIHoverGestureRecognizer` + `UIPointerInteraction` を組み合わせてポインタ座標/ボタンを取得。
- 取得イベントは `InputEvent` プロトコルへマッピングし、差分（Δx/Δy、KeyDown/KeyUp）だけ CBOR でシリアライズ。
- Controller 側でイベント再生: `RemoteInputInjector` が SwiftUI の `FocusState` と `UIResponder` チェーンに注入、Pointerは `PointerProjectionLayer` を介して remote cursor overlay。

## 3. 画面共有
- Display役は2通りのソースを持つ:
  1. `ReplayKitScreenSource`: アプリ全体の画面（アプリ領域のみ）をキャプチャ。サンプルバッファを `VideoToolbox` でH.265低遅延モードに圧縮。
  2. `MetalRenderSource`: SwiftUI/Metalで構築した専用描画サーフェスを直接シリアライズし、カラー圧縮（ASTC）後に送信。
- 受信側 `RemoteDisplayRenderer` は `MetalKit` でテクスチャを復元し、フレーム同期は `displayLink` ベースで行う。
- 音声は `AVAudioEngine` のTapを利用し、Opusコーデック（[swift-opus](https://github.com/lvwzhen/SwiftOpus) 等）をSPMで統合予定。

## 4. QoS / 遅延対策
- `LatencyEstimator` が100ms毎にRTTを計測し、`InputBridgeService`へ通知。
- RTTが閾値を超えたら `FrameCompressor` のビットレート/解像度を自動調整。
- ジッタに備えた `FrameBuffer` (triple buffering) と `InputEvent` の再送メカニズム（Sequence番号 + ACK）。

## 5. UI構成
```
RootView
├─ ConnectionStatusBanner
├─ RolePickerView (Controller / Display / Mirror)
├─ AdaptiveContentView
│   ├─ ControllerView: RemoteDisplay + InputCapture controls
│   └─ DisplayView: ScreenShare controls + Pointer overlay
└─ SettingsSheet
    ├─ ビットレート/解像度
    ├─ 入力感度
    └─ ログ出力
```

## 6. 検証計画
- `Tests/SharedControlKitTests`: 入力イベントシリアライズ、RTT推定のユニットテスト。
- `UITests`: 疑似セッションを立ててカーソル追従を検証（`XCTestExpectation`）。
- 実機計測: `TelemetryLogger` が `metrics.jsonl` を生成し、RoundTripLatency, FrameDrop率を記録。
- `Fastlane` で `scan` → `gym` を設定し、TestFlight配信までを自動化予定。
